# Playground

## Snakeroids

Snake meets Asteroids. Open `snakeroids/index.html` in a browser — no build, no dependencies.

- ← → turn, ↑ boost, Space fire, P pause (touch buttons on mobile)
- Eat small green rocks to grow; big rocks kill you if you hit them head-on
- Shoot big rocks to split them into snacks; rocks that cross your body chop off the tail
- Screen edges wrap; clear all rocks to start the next wave
